迁移备份

DATA / MIGRATION

迁移到无网络电脑 · 操作指引 HOW TO MOVE OFFLINE

  1. 在有网的机器上打开「包管理」，把需要的公共包「添加」进来（tarball 会被缓存到本机）。
  2. 回到本页，在「导出备份」中选择范围（建议 全部 或 仅公共缓存），点击导出 bundle。
  3. 在下方「bundle 历史」里点下载，把生成的 .tar/.tgz bundle 拷到 U 盘。
  4. 把 U 盘插到无网络的电脑，启动本镜像源服务，打开本页，在「导入备份」里拖入 bundle 文件（或选择服务器上已有的 bundle）。整机备份往往有几个 GB：超过网页上传上限的包请直接放进 data\bundles 目录，刷新本页后在「服务器上已有」里点「导入」，这条路不受上传上限限制。
  5. 若该电脑装过 npm 全局包，可再用「从本机 npm 缓存导入」把 _cacache 里的包直接搬进镜像源，无需联网。
  6. 导入完成后在「配置」页生成客户端 .npmrc，让其它项目指向本镜像源即可离线安装。

服务控制 CONTROL

局域网共享 LAN SHARING

  • 确保「配置 → 服务 IP」为 0.0.0.0，浏览器访问 http://<本机IP>:<端口>/。
  • 若其它电脑连不上，在 Windows 防火墙放行该端口： netsh advfirewall firewall add rule name="npm-mirror" dir=in action=allow protocol=TCP localport=4873
  • 局域网客户端建议关闭免鉴权（security.trustLocalhost=false 或按需开启 requireRead/requirePublish），并分发 token。
  • 客户端 .npmrc 用本机 IP（见「配置」页生成的接入配置）。
